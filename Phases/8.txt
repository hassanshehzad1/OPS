### Key Learning Is Phase Mein
- **`$json.output.decision` vs `$json.decision`** — field path ka exact structure match karna zaroori hai, warna value silently undefined ho jati hai aur Switch node koi bhi branch match nahi karta
- Expression mode mein switch karte waqt **copy-paste se accidental whitespace/tab characters** aa sakte hain — hamesha clean retype karna safe hai
- 3 parallel branches (Auto/Approval/Escalate) ko wapis combine karne ke liye **Merge node (Append mode, 3 inputs)** use kiya

### Final Architecture
```
Decision Engine (decision field)
      ↓
Decision Router (Switch)
  ├── AUTO_EXECUTE → Execute Action
  ├── NEEDS_APPROVAL → Create Approval Request
  └── IMMEDIATE_ESCALATE → Send Urgent Alert
      ↓
Combine Execution Results (Merge)
      ↓
Insert rows in a table (PostgreSQL)
```
