Step 1 — Code node add karo (validation ke liye)

n8n canvas mein, Webhook node ke baad ek Code node add karo (ya IF node, lekin Code node zyada flexible hai). Us mein ye logic likho:

javascript
const body = $input.item.json.body;

const required = ['incident_id', 'customer_id', 'order_id', 'message', 'source'];
const missing = required.filter(field => !body[field]);

if (missing.length > 0) {
  return [{
    json: {
      status: "rejected",
      reason: `Missing fields: ${missing.join(', ')}`
    }
  }];
}

return [{
  json: {
    status: "accepted",
    incident: {
      incident_id: body.incident_id,
      customer_id: body.customer_id,
      order_id: body.order_id,
      message: body.message,
      source: body.source,
      timestamp: body.timestamp || new Date().toISOString(),
      received_at: new Date().toISOString()
    }
  }
}];

Note: agar tumhare payload mein incident_id nahi hai (jo tumne pehle test mein nahi bheja), to ya to isko required list se hata do, ya khud generate kar lo Code node mein (incident_id: body.incident_id || 'INC-' + Date.now()).
